# نتایج اجرای محیط جدا

آزمایشگاه روی checkout خالی پروژه توسعه داده شد. هیچ پنل یا نود فعال در
این محیط متصل نشده است. تنها مقصد Git پروژه برای انتشار کد استفاده می‌شود.

| بررسی | نتیجه و دامنه |
|---|---|
| ساخت Docker روی Ubuntu 24.04، amd64 | موفق، تصویر پایه با digest در Dockerfile ثابت شده |
| اجرای `docker compose run --rm compatibility` | ۲۴ تست اجرا شد؛ ۲۴ پاس، صفر fail، صفر skip |
| اجرای محلی Python 3.12 | ۲۳ پاس؛ یک smoke مربوط به OpenVPN به علت نبود باینری در میزبان skip شد |
| جمع مصرف با توابع رسمی پنل | UID مشترک، دو جهت، دو نود و کاربر فقط OpenVPN در سطح aggregation تأیید شد |
| دفتر SQLite | نمونه پایانی، نمونه تکراری، ری‌استارت bridge، epoch جدید، reset هم‌زمان و مرگ ناگهانی فرآیند پس از commit تأیید شد |
| قطع socket پس از reset | نقص قرارداد بازتولید شد: ۳۰۰ بایت در پنل fixture ثبت نشد |
| تکرار گزارش موفق | نقص قرارداد بازتولید شد: مقدار ۳۰۰ به ۶۰۰ بایت رسید |
| خرابی پنل پس از دریافت، پیش از commit | نبود راه تشخیص موفقیت commit از سمت نود در fixture نشان داده شد |
| انقضا و اتمام سهمیه | فقط مدل پیام حذف دسترسی/رد اتصال؛ قطع تونل واقعی آزمایش نشده |
| OpenVPN واقعی | فرآیند با dev null و management-hold شروع شد و رابط Unix management به version پاسخ داد؛ تونل/ترافیک ایجاد نشد |
| پنل کامل، دیتابیس واقعی، scheduler | اجرا نشده |
| احراز هویت VPN، NAT، انتقال و قطع ترافیک واقعی | اجرا نشده |
| پنل فعال و نود فعلی | دسترسی یا تغییری انجام نشده |
| انتشار محیط ابری و بازیابی در task تازه | توسط این آزمایش‌ها تأیید نشده |

رفع خطای build: pip در کانتینر CA پراکسی محیط را نداشت. از Compose override
و BuildKit secret برای mount موقت CA bundle میزبان استفاده شد؛ TLS verification
غیرفعال نشد و CA در لایه تصویر کپی نشد. نخستین اجرای Docker به علت مالکیت
دایرکتوری‌ها صفر تست پیدا کرد و شکست خورد؛ مالکیت COPY برای کاربر غیر root
اصلاح شد و اجرای نهایی هر ۲۴ تست را اجرا کرد.

اجرای مجدد:

```sh
cd /workspace/openvpnpa
docker compose -f compose.yaml -f compose.cloud.yaml build
docker compose run --rm compatibility
```

در محیط بدون پراکسی خاص، `docker compose build` کافی است. گزینه cloud فقط
trust میزبان را به مرحله نصب pip می‌دهد و پورت، اتصال پنل یا سرویس VPN باز نمی‌کند.
