# نسخه v0.2.0-beta.9

مبنای بررسی: شاخه main و تگ v0.2.0-beta.8 هر دو روی
`d5bab2f3fd304d7e90c2347aece1f85830875449` بودند.

- گزینه `auth-user-pass-optional` بلافاصله پس از `management-client-auth`
  به تنظیمات سرور افزوده شد؛ گواهی کلاینت همچنان اجباری است.
- دریافت تمام صفحات API کاربران با `offset`، `limit` و ترتیب `username`
  اضافه شد. این پارامترها و مدل `users`/`total` در منبع رسمی پاسارگارد
  v5.5.1 بررسی شدند. شروع سرویس و چرخه دوره‌ای با فاصله ۱۵ ثانیه پس از
  پایان هر چرخه، فهرست را تازه می‌کنند. محدودیت تعداد هر صفحه سمت سرور
  نیز رعایت می‌شود. صفحه ناقص یا بدون پیشرفت، خطا می‌دهد؛ در صورت خطا،
  کاربران شناخته‌شده جداگانه تازه می‌شوند و تازگی cache در شکست تمدید نمی‌شود.
- ثبت محلی با UID اصلی upsert می‌شود؛ حساب یا عضویت گروه در پاسارگارد
  خودکار ساخته نمی‌شود. فقط کاربران قابل‌دیدن برای توکن API وارد می‌شوند.
- ورود به فهرست مستقل، مجوز اتصال نیست. مجوز همچنان به Start تازه،
  همگام‌سازی inbound اختصاصی گروه openvpn و وضعیت معتبر API وابسته است.
- IP/دامنه تانل و پورت UDP کلاینت در صفحه اصلی افزوده شد. تنظیم در
  جدول موجود تنظیمات محلی ذخیره می‌شود؛ migration یا تغییر ساختار دیتابیس
  لازم نیست. فقط خط remote دانلودهای بعدی تغییر می‌کند و کلید/گواهی
  قبلی همان UID حفظ می‌شود. مقدار خالی از آدرس/پورت اصلی استفاده می‌کند.

هیچ تغییری در پنل اصلی، دیتابیس آن، کانتینر یا نود V2Ray انجام نشده است.
L2TP و OpenConnect اضافه نشده‌اند. UI جدید فارسی و پیام‌های اجرایی ASCII هستند.

## شواهد آزمایش

محیط Python محلی: ۷۶ تست؛ ۷۳ موفق و ۳ skip وابسته به OpenVPN/محیط.
داخل تصویر آزمایش Ubuntu 24.04 با OpenVPN: **۷۶ تست، همگی موفق، بدون skip**.
ساخت تصویر با TLS verification فعال انجام شد:

```sh
docker compose -f compose.yaml -f compose.cloud.yaml build
docker run --rm --network none --read-only \
  --tmpfs /tmp:rw,exec,nosuid,size=64m --cap-drop ALL \
  --security-opt no-new-privileges:true openvpnpa-compatibility
```

پوشه موقت باید برای اسکریپت‌های شبیه‌سازی‌شده تست نصب قابل‌اجرا باشد؛
noexec پیش‌فرض compose آزمایش مانع اجرای این تست‌ها می‌شود. این فرمان
فقط scratch کانتینر آزمایش را تغییر می‌دهد؛ تنظیم کانتینر سرویس تغییر نکرد.

تست‌های تازه، چندصفحه‌ای بودن با سقف کوچک‌تر سمت سرور، صفحه ناقص/تکراری،
خطای میانه دریافت، UID ثابت و تغییر نام بدون تکرار، جدایی import از مجوز
inbound، ماندگاری تنظیمات تانل، مقدار خالی، جلوگیری از تزریق، و تغییر فقط
remote در محتوای پروفایل را بررسی می‌کنند. تست کانفیگ سرور، ترتیب گزینه
جدید و اجباری‌بودن گواهی را بررسی می‌کند و با OpenVPN واقعی تا مرز TUN می‌رود.

تونل واقعی و پنل زنده کاربر در این محیط در دسترس نیستند؛ انتقال ترافیک
و رفتار نصب زنده پاسارگارد v5.5.1 تأیید نشده است.
